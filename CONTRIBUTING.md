# Maintaining mocha-compat

The fork's guide — branch layout, versioning, dist-tags, both release procedures and the traps —
lives once on the `master` branch so it cannot drift between the two lines:

<https://github.com/kmalakoff/mocha-compat/blob/master/CONTRIBUTING.md>

    git show master:CONTRIBUTING.md

Upstream mocha's contributor guide is `.github/CONTRIBUTING.md` and still applies to the mocha code.
